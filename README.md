# Adaptive-Modulation-Classification-USRP
Victor Carr    Contributors: Oscar Miranda, Jack Wyatt
Bachor's of Science, Electrical Engineering
East Texas A&M University-Commerce
4/22/26

This project investigates the implementaion of an adaptive modulation framework using National Instruments USRP software-defined radios. By combining digital signal processing with machine learning techniques, the system demonstrates how communication links can intelligently recognize signal characteristics and adapt transmission stratigies.
